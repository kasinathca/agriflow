# Methodology summary

AgriFlow analyses daily log-price returns using lagged association, minimum overlap and
effect-size thresholds, then controls multiple tests with Benjamini-Hochberg FDR. Directed
leader-to-follower edges feed source-oriented influence scores and market-integration
summaries. Geography uses Haversine distance with a QAP-style label-permutation diagnostic.
Weather analysis uses gridded NASA POWER values and declustered descriptive event studies.
Arrival-price crunch flags are associations, not causal estimates.

Final numerical claims require a REAL, paper-acceptable, checksum-verified freeze. No such
freeze exists in the current credential-free environment.
